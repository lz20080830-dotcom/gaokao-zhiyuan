# 高考志愿查询助手（订单班冲稳保匹配工具）

面向高考生与家长的**高就业确定性**志愿填报辅助工具，聚焦于各省订单班、定向培养、军士/警校、医学定向、国企定向等就业有保障的专业与院校。

- **在线访问 (GitHub Pages)**: [https://lz20080830-dotcom.github.io/gaokao-zhiyuan/](https://lz20080830-dotcom.github.io/gaokao-zhiyuan/)
- **PWA 支持**: 支持离线缓存与添加到移动端主屏幕，体验媲美原生 App。

---

## 核心特性

- **冲稳保三档匹配**：输入生源省份与高考预估分数，算法依据历年投档线与位次自动测算推荐。
- **重点行业全覆盖**：覆盖电力电网、铁路轨道、航空民航、公安司法、定向军士、医学定向、邮政通信、公费师范、海关/海事等领域。
- **避坑与履约透视**：详细展示各项目**用工性质**（正式编制/合同制）、**服务年限**、**违约成本与风险等级**。
- **横向对比与方案库**：支持多项目加入对比表格，保存专属志愿备选方案。
- **31 省政策速览**：汇总全国各省志愿填报批次、投档规则及注意事项。

## 项目架构与技术栈

本 Web 端为 **uni-app (Vue 3 + Vite)** 多页面架构打包产物，集成 PWA 离线能力：

```
gaokao-web/
├── index.html            # Web 入口主页（单页挂载与 SEO/PWA 配置）
├── manifest.webmanifest  # PWA 应用清单（应用名称、图标、主题色）
├── sw.js                 # Service Worker（智能动态离线缓存，网络优先回退）
├── assets/               # Vite 构建后的样式与业务脚本
├── icons/                # PWA 多尺寸高清桌面图标
├── static/               # TabBar 与各模块静态图标
└── README.md             # 本文档
```

## 数据维护与更新指南

数据源由上游工程 `gaokao-uniapp/src/data/db.js` 统一管理：

1. **修改数据**：
   在源码工程 `gaokao-uniapp/src/data/db.js` 中编辑项目库 `PROJECTS` 及各省政策配置。
2. **构建 H5 产物**：
   ```bash
   cd gaokao-uniapp
   npm run build:h5
   ```
3. **同步产物到 Web 目录**：
   执行同步脚本将构建产物同步至 `gaokao-web/`，确认变更后提交推送至 GitHub 即可自动通过 GitHub Pages 刷新上线。
