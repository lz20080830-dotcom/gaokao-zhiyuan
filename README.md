# 高考志愿查询助手（订单班冲稳保匹配工具）

纯静态单页应用：选省份、填分数，按 **冲稳保** 三档匹配订单班 / 定向培养 / 稳定就业类院校专业，并提供用工性质、服务年限、违约风险等避坑信息。

- 覆盖领域：电力、铁路轨道、航空民航、公安司法、定向军士、医学定向、邮政通信、师范定向、海关/消防/机要、船舶海事
- 数据规模：69 个项目（参考分 260-665）+ 31 省志愿填报政策速览
- 技术栈：零依赖单文件 HTML + 原生 JavaScript（数据即 `index.html` 中的 `const P = [...]` 与 `PROVINCES` 数组，改数据直接编辑即可）

## 更新数据

编辑 `index.html` 中 `const P=[...]`（项目库）和 `const PROVINCES=[...]`（省份政策），保存后推送即自动更新页面。

## 免责声明

参考分基于 2025/2026 年各省公开投档数据及院校招生信息整理，**仅供参考，不构成报考依据**；每年招生计划与政策可能调整，最终以各省教育考试院与院校招生办公布为准。
